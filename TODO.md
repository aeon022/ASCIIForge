## 🚀 Polar.sh Dashboard Setup Overview

Log in to your Polar Dashboard: **[polar.sh/dashboard](https://polar.sh/dashboard)**

For each tool below:
1. Go to **Products** $\rightarrow$ **New Product**.
2. Set product type to **Digital Product / License Key**.
3. Enable **Generate License Keys** on purchase.
4. Copy the resulting **Checkout Link / Product ID**.
